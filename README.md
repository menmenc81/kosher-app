# כושר ב־15 דקות: התקנה עצמאית

האפליקציה היא אתר סטטי. מעלים אותו פעם אחת ל־GitHub Pages, בחינם, ומתקינים בטלפון.

## העלאה ל־GitHub Pages (בערך 5 דקות, אפשר מהמחשב)

1. היכנס ל־github.com ולחץ **New repository**.
   - שם: למשל `kosher-app`
   - סמן **Public**. ב־GitHub Pages בחינם המאגר חייב להיות ציבורי. הקוד יהיה גלוי, אבל הנתונים שלך נשמרים רק בטלפון.
   - לחץ **Create repository**.
2. בעמוד המאגר החדש, לחץ **uploading an existing file**.
3. גרור לחלון את כל הקבצים מתוך התיקייה (לא את התיקייה עצמה):
   `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
4. לחץ **Commit changes**.
5. עבור ל־**Settings ← Pages**. תחת **Branch** בחר `main` ואת התיקייה `/ (root)`, ולחץ **Save**.
6. אחרי דקה או שתיים תופיע הכתובת:
   `https://<שם-המשתמש-שלך>.github.io/kosher-app/`

## התקנה בטלפון (אנדרואיד)

1. פתח את הכתובת **בכרום**.
2. תפריט ⋮ ← **התקנת אפליקציה** (או "הוספה למסך הבית").
3. האפליקציה תופיע עם אייקון משלה, תיפתח במסך מלא ותעבוד גם בלי אינטרנט.

## חשוב לדעת

- **הנתונים נשמרים בטלפון בלבד.** אם מוחקים את נתוני כרום או מחליפים טלפון, הם יימחקו. בהגדרות יש כפתור **"⬇ הורד קובץ גיבוי"**. מומלץ להוריד גיבוי פעם בחודש.
- **עדכונים:** כשמחליפים קובץ במאגר, הטלפון מוריד את הגרסה החדשה ברקע. היא מופיעה בפתיחה שאחרי.
- **מעבר מהגרסה ב־Claude:** בגרסה הישנה, בהגדרות, לחץ "העתק גיבוי". בגרסה החדשה, בהגדרות, לחץ "שחזר מגיבוי" והדבק.
